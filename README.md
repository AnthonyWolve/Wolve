# Wolve

The portfolio of Anthony Wolve Eigbe. Creative Director, Lagos.

Seen. Experienced. Remembered.

## How this site works

- `index.html` is the whole site: layout, styles and the code that switches between pages.
- `assets/` holds the photos, posters and video clips.
- The site is hosted free by GitHub Pages straight from this repository. Any change pushed here goes live in about a minute.

## Making a change

1. Open a file on github.com and click the pencil icon to edit.
2. Click "Commit changes".
3. Wait a minute, then refresh the live site.
